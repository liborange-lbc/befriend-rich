# #7 定投策略增强

## 概述
智能定投（基于偏离度动态调整金额���、止盈策略（阶梯止盈）、多策略组合回测。

## 设计

### 后端
- **扩展** `backend/app/services/backtest/engine.py`
  - 新增 buy_type: "smart_dca" — 根据偏离度动态调整定投金额
    - 偏离度 < -10%: 1.5x基础金额
    - 偏离度 -10%~-5%: 1.2x
    - 偏离度 -5%~5%: 1.0x
    - 偏离度 5%~10%: 0.8x
    - 偏离度 > 10%: 0.5x
  - 新增 sell_type: "ladder" — 阶梯止盈
    - 收益10%时卖出30%仓位
    - 收益20%时再卖30%
    - 收益30%时卖剩余

- **新增API** `POST /api/v1/backtest/portfolio` — 多基金组合回测
  - 接收 [{fund_id, config}] 列表
  - 返回组合层面的 equity_curve 和 metrics

### 前端
- 回测页面扩展：策略配置增加智能定投和阶梯止盈选项
- （组合回测可作为高级功能后续UI化）

### 技术决策
- 直接扩展现有引擎，保持向后兼容
- 智能定投基于 dev_60（60日偏离度），可配置
- 阶梯止盈使用部分卖出（追踪剩余份额）
